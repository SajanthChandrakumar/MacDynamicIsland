# Focus Timer Implementation Plan

## Goal
Implement priority 1 approved in chat: countdown/Pomodoro, optional free title or Apple reminder, compact timer alongside music. Existing macOS EventKit accounts include Google calendars configured on the Mac; no separate Google login/Tasks work.

## Global Constraints
- User explicitly requests all subagents `gpt-6-luna`, reasoning effort `xhigh`, isolated context, no nested subagents.
- Ponytail: reuse existing SwiftUI/AppKit/Defaults patterns, no new dependencies, no generic frameworks or unrelated refactors. Preserve neighboring style, existing directories, English identifiers and string catalog.
- One active session shared by all screens; preserve 640x190 expanded dimensions, current fullscreen settings, existing music/Shelf functionality.
- Countdown 25/50/custom whole minutes (1...180). Pomodoro defaults 25 work/5 short/15 long after4 work, editable work/break durations 1...180 and interval 1...12. Snapshot settings per session; changes affect new sessions.
- Every phase transition is manual. Timer completion never completes an associated reminder; manual reminder completion never stops a timer. Phase-end visual only, once, no sound/notification permissions/focus stealing.
- Lock/sleep pause, no automatic resume. On restart restore last persisted remainder paused without charging app-off time. Already completed phases remain completed. Persist transitions, not every second. Abrupt kill restores last checkpoint.
- Direct Focus-tab input is intentional-keyboard-focus only; hovering never activates app. Keep open while editing/selecting, release on Escape/dismissal.
- Feature branch in existing checkout `codex/focus-timer` as approved. Root coordinates commits/build configuration; no remote push/deployment.

## Task 1: Focus state, manager and native tests

Own new `boringNotch/models/FocusSession.swift`, `boringNotch/managers/FocusManager.swift`, `boringNotchTests/FocusSessionTests.swift`, relevant new Defaults keys in `models/Constants.swift`, and native non-hosted XCTest target/scheme registration in project.pbxproj/.gitignore/shared scheme. No UI/EventKit edits.

Build pure Foundation Codable/Equatable model types `FocusMode` (countdown,pomodoro), `FocusPhase` (work,shortBreak,longBreak), `FocusStatus` (idle,running,paused,completed), `FocusSettings`, `FocusTask` (title,optional reminderID,optional listName), and `FocusSession`. Keep all Foundation types in one small source file. Session owns state transitions so native XCTest can compile the same model source without app launch or external packages. Time is a Date parameter to model operations, clamped remainder. Timer ticks calculate elapsed from anchors, never subtract one per tick. Repeated expiry/pause calls are idempotent; completed work count advances once on completed work only. Pomodoro advance picks long break at the configured interval, otherwise short, then work. Countdown completion remains completed until new session/end. End resets to idle. Restoring a running snapshot clears its anchor and restores its checkpoint paused; completed stays completed. Decode/sanitize invalid state/settings safely.

`@MainActor final class FocusManager: ObservableObject` follows singleton patterns, publishes `session`, `remainingSeconds`, `settings`, `completionNoticeVisible`; exports `start(mode: FocusMode, minutes: Int, task: FocusTask?)`, `pause()`, `resume()`, `advancePhase()`, `stop()`, `markReminderCompleted()` (detach reminder association only, keep title/session running). Session exposes `mode`, `phase`, `status`, `task`, `completedWorkSessions`, computed next-phase information and `remaining(at:)`. Manager stores with existing Defaults, with Codable serialization/conformance kept app-side so model stays Foundation-only. Own one cancellable timer task; no tick while idle/paused/completed. Expiry marks completed and publishes a single three-second visual flag, without auto advancing. Cancel prior notice tasks on new session/stop. Publish model transition before persistence, snapshot current remainder at transitions. Manager observes NSWorkspace.willSleepNotification once, deinitialization releases observer/task; existing AppDelegate screen-lock hook will call pause in Task3. Expose a production `setTask(_:)` only if needed to detach completed/unavailable reminder while preserving title.

TDD: add behavioral failing tests before model code, record RED/GREEN. Tests use fixed Date values: countdown delayed tick/expiry once, exact pause+resume remaining, duplicate pause, manual Pomodoro gate and fourth-work long break, break doesn't increment work count, settings snapshot, zero/invalid configuration, Codable round trip and running->paused restoration with no offline consumption, countdown end and task association preserved. Non-hosted XCTest bundle compiles model source + tests; no TEST_HOST/BUNDLE_LOADER. Explicitly track shared test scheme despite existing *.xcscheme ignore. Use existing scheme/app metadata; no dependency updates.

Run focused native tests using xcodebuild/macOS; dependency-free test scheme should avoid building app. Commit only owned files, report API exact signatures and command evidence. Write report to the path in dispatch.

## Task 2: Open reminders and truthful completion

Own CalendarServiceProviding.swift, CalendarManager.swift and focused native reminder mapping tests/project test-source registration. Read Task1 model and use its FocusTask contract. Do not edit UI, FocusManager or session logic.

Add separate EventKit query for incomplete reminders including missing due dates, using current selected reminder lists. No-due reminders must not be forced into EventModel (which requires date). Produce FocusTask(title,reminderID,listName), stable IDs, due tasks first then title, and refresh on existing EKEventStoreChanged notifications. Ensure explicit empty reminder selection does not mean all calendars; preserve existing Calendar day-query semantics. CalendarManager publishes focus reminder choices/loading/error and provides async explicit load with permission on user selection. Permission failure leaves free-title use available; newly denied access clears stale choices. Update authorization state accurately and avoid duplicate state tasks overriding it.

Add completion method throwing truthful not-found/access-denied/not-writable/save errors; use it through CalendarManager for focus completion. Preserve existing calendar callers by keeping current wrapper and handling thrown errors appropriately. Expose `loadFocusReminders() async`, `completeFocusReminder(id: String) async throws`, published `focusReminders`, `focusRemindersLoading`, `focusRemindersError` (names fixed unless clear build conflict). On successful completion refresh both focus list and calendar day view. Do not mutate live account reminders during automated tests. A stale linked reminder must be visibly unavailable in UI but keep its title/timer. Test in-memory EKReminder mapping (no store access) for due/undated/completed, selected-list boundary as pure helper only if real logic requires it; prefer smallest meaningful tests, no source-text tests or elaborate mocks.

Ensure generated modern macOS reminder/calendar usage keys are valid for existing requestFullAccess methods in both app configurations; use SDK documentation rather than guessing legacy key behavior. Explain purpose truthfully. Coordinate project registration after Task1. Commit scoped files, report APIs and tests.
